# 🌱 Plant Hotel Management System

Java application for managing plant watering schedules using OOP principles.

## 🚀 Setup

1. Clone the repository
2. Run `Huvudprogram.java`
3. Enter plant name when prompted

## ✨ Features

- 💧 Calculate daily water requirements
- 🌵 Support for multiple plant types (Cactus, Palm, Carnivorous)
- 📊 Automatic liquid type and amount calculation
- 🔍 Search plants by name
- ⚠️ Input validation and error handling

## 🎯 OOP Concepts Demonstrated

- **Inheritance** - Abstract `Växt` superclass with plant subclasses
- **Polymorphism** - Override methods for plant-specific calculations
- **Encapsulation** - Private fields with public getters
- **Interface** - `VätskaBeräkning` for liquid calculations
- **Enum** - `VätskeTyp` and `Enhet` for type safety

## 🛠️ Tech Stack

Java • Swing GUI • OOP Design Patterns
